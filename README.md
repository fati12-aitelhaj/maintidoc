# MaintiDoc

Assistant documentaire multimodal et agentique pour la maintenance
(projet intégrateur IA générative multimodale, EMSI 2026).

## Équipe
- Aya Ijenha
- Fatima Ezzahrae Aitelhaj

## Objectif
Aider les techniciens de maintenance (distributeurs de billets et
terminaux de paiement) à obtenir des réponses sourcées à partir de
manuels, de schémas et de photos.

## Structure du dépôt
- docs/diagrammes/ : sources des diagrammes
- corpus/ : documents, inventaire.csv, prompts_corpus.md
